### In this page we will discuss some resources to learn the background, parameters and theory of ADCIRC.

1. **[ADCIRC Live Tools](https://tools.adcirc.live/)**-
This website will help you to download the ADCIRC. The instructions are written how you can get access to ADCIRC.

2. **[ADCIRC Wiki](https://wiki.adcirc.org/Main_Page)**-
This will help you to get overall idea about ADCIRC files and parameters.

3. **[ADCIRC User Manual](https://adcirc.org/home/documentation/users-manuals-compile-options-faqs-wiki/)**-
This is the official user manual

4. **[ADCIRC GitHub](https://github.com/adcirc)** — 
   source code, releases, and development updates for ADCIRC, also some test files

5. **[SWAN+ADCIRC](https://ccht.ccee.ncsu.edu/swanadcirc/)** — 
   A page for SWAN coupled with ADCIRC, includes 
   documentation and example applications developed by NC State University

6. **[SMS Learning Tutorials](https://aquaveo.com/software/sms/learning-tutorials)** — 
   official tutorials for SMS software used to 
   make different files of ADCIRC

7. **[OceanMesh2D](https://github.com/CHLNDDEV/OceanMesh2D)** — 
   MATLAB mesh generation toolbox for creating unstructured 
   meshes for ADCIRC

8. **[WinSCP](https://winscp.net/eng/download.php)** — 
   free file transfer tool to move files between your 
   local computer and HPC cluster. You can use other software, but I normally use this.

9. **[MobaXterm](https://mobaxterm.mobatek.net/)** — 
   free terminal and SSH client for connecting to 
   HPC clusters from Windows. You can use other software, but I normally use this.

10. **[Aquaveo YouTube Channel](https://www.youtube.com/@Aquaveo/playlists)** — 
    video tutorials and playlists for SMS software

11. **[RiverGeeks YouTube Channel](https://www.youtube.com/@RiverGeeks)** — video tutorials and playlists on SMS


12. **[TPXO Global Tidal Model](https://www.tpxo.net/)** — global ocean tide model (e.g., OSU TPXO9) providing tidal constituent data used to generate ADCIRC tidal boundary forcing (fort.15 tidal amplitudes and phases). This data is provided by Oreon State University, but you need to email them to get access of this data. The procedure is written in their website.

Besides these resources, you can joind ADCIRC Discord group, slack group and OceanMesh2D slack group.
