### Mesh Generation

The first thing that you need to run ADCIRC is a mesh file. That mesh file is called fort.14. There are many ways that you can use to generate mesh. First of all, you can collect any fort.14 file already created by others. But sometimes, you also need to build your own mesh. ADCIRC mesh building is a challenging task, because you will mostly build the mesh for coastal area which is always complex. The mesh file build can be done in two ways:

1. SMS software: Mesh can be build inside SMS. There are many tools which you can use to build mesh. Suppose, you have to build a mesh for North West Atlantic and include the floodplain as well. In general what we do is taht, make the ocean side mesh coarser, and floodplain side or bay side of your area of interest more finer. Mesh building mainly depends on your judgement, because more nodes will not help you always as it can increase the runtime on HPC significantly. Making mesh in SMS sometimes can be slow when you have millions of nodes. So, in most cases, people now use a MATLABpackage and code that is called Ocean Mesh 2D.

2. OceanMesh 2D: The OM2D is a MATLAB package that is developed by University of Notre Dame. In general, what it do is, say you gave the DEM file, coastline shapefile in the code, and the package have many functions that it use to generate the triangular mesh automatically for you when you run the code. You can make coarser, or finer resolution mesh with this. The main advantage is that it is fast and you do not need that much of manual editing. But sometimes, you may need to take the genrated mesh in SMS and edit some elements manually to make the mesh stable. OM 2D has very good documentation and examples of how you can generate a mesh. I will suggest to go through their github page and practice those examples and understand wha the functions do. Initially, it can be hard to understand, but eventually you will be used to it. Also, if you have any questions, you can ask in their slack group and they will help.
